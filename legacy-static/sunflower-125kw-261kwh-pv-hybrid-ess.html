FAQ

Questions before choosing this product.

What does PV-hybrid mean?

It is intended for solar + storage configurations where PV input and backup output are part of the system design.

Is 250kW PV input always usable?

It is a stated system capability, but final PV string design and local code must be confirmed.

Where does it fit best?

Commercial solar projects, EV charging support and C&I backup applications with PV integration.
