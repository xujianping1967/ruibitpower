FAQ

Questions before choosing this product.

Is 10kWh enough for a house?

It can cover many essential-load or evening self-consumption use cases, but whole-home backup depends on actual loads.

Can it pair with third-party inverters?

Compatibility depends on inverter brand, protocol and battery settings. Send the inverter model before quotation.

Is it suitable for installers?

Yes, it is a common residential capacity class for solar installers and distributors.
